# 🔋 バッテリー交換実績集計アプリ

PT企業（user_company）毎に、user_nameと自転車メーカー別のバッテリー交換実績を集計し、Excel出力するアプリケーションです。

## 📋 機能

- ✅ Excelファイル（バッテリー交換実績データ）の読み込み
- ✅ PT企業毎に自動集計
- ✅ user_name × 自転車メーカー名 のクロス集計表を生成
- ✅ **基準内/基準外の判定と集計**（ベクトル演算による高速処理）
- ✅ **重複検出**（前後1時間以内の同一車両番号レコードを自動検出・除外）
- ✅ **自社交換分の自動除外**（対象PT企業のbike_company一致レコードを集計から除外し別管理）
- ✅ 全PT企業の集計結果＋生データをZIPで一括ダウンロード
- ✅ **bike_company毎のローデータをExcelで個別ダウンロード**（ピボットシート付き）

## 🚀 セットアップ

### 1. 必要なパッケージのインストール

```bash
pip install -r requirements.txt
```

### 2. アプリケーションの起動

```bash
streamlit run app.py
```

ローカル開発時に認証をスキップする場合は、環境変数 `DISABLE_AUTH=true` を設定してください。

```bash
DISABLE_AUTH=true streamlit run app.py
```

ブラウザが自動的に開き、アプリケーションが表示されます。

## 📖 使い方

### 基本的な使い方

1. **ファイルのアップロード**
   - サイドバーから「Excelファイルをアップロード」ボタンをクリック
   - バッテリー交換実績データのExcelファイルを選択

2. **集計実行**
   - 「🔄 集計実行」ボタンをクリック
   - 重複検出・自社交換分除外・基準判定が自動的に実行されます

3. **結果のダウンロード**
   - **全PT企業一括**: 全社分の集計結果＋生データをZIPファイルでダウンロード
   - **bike_company別**: ダウンロードしたい会社を複数選択して個別Excelをダウンロード

## 📊 データ形式

### 入力データ（Excel）

必須列：
- `user_company(所属)`（V列）: PT企業名
- `user_name`: ユーザー名
- `自転車メーカー名`: 自転車のメーカー名
- `battery_remaining`: バッテリー残量（基準判定に使用）
- E列（bike_company等）: 交換実施会社名
- `do_date`: 交換日時（重複検出に使用）
- `code`: 車両番号（重複検出に使用）

### 出力データ（集計結果）

各PT企業毎に以下の形式で集計：

| user_name | Panasonic_基準内 | Panasonic_基準外 | Panasonic_合計 | Panasonic_重複除外数 | ... | 総合計 | 総重複除外数 | 全メーカー_基準内 | 全メーカー_基準外 | 全メーカー_判定なし | 検証_基準内+判定なし |
|-----------|-----------------|----------------|--------------|-------------------|-----|-------|------------|---------------|---------------|----------------|-----------------|
| ユーザー1   | 80              | 20             | 100          | 3                 | ... | 167   | 5          | 125           | 35            | 7              | 132             |
| ...       | ...             | ...            | ...          | ...               | ... | ...   | ...        | ...           | ...           | ...            | ...             |
| 合計      | 150             | 30             | 180          | 8                 | ... | 326   | 12         | 240           | 70            | 16             | 256             |

#### バッテリー残量基準

各メーカーの基準外判定：
- **Panasonic**: 25%以上が基準外（25%未満が基準内）
- **YAMAHA**: 70%以上が基準外（70%未満が基準内）
- **DBS**: 50%以上が基準外（ただし100%は基準内）
- **glafit**: 50%以上が基準外（50%未満が基準内）
- **シナネンサイクル**: 40%以上が基準外（40%未満が基準内）
- **KUROAD**: 基準判定なし

#### 重複検出ルール

`do_date`（交換日時）と`code`（車両番号）を基に、同一車両の前レコードから1時間以内のレコードを重複として検出します。重複レコードは集計から除外し、`*_重複除外数`列に件数を記録します。

#### 自社交換分の除外

以下の「E列のbike_company」と「V列のPT企業名」の組み合わせに該当するレコードは自社交換分として集計から除外され、Excel出力時に「自社交換分」シートへ格納されます。

| E列（bike_company） | V列（user_company(所属)） |
|-------------------|------------------------|
| トヨタモビリティ東京株式会社 | TMT |
| 江ノ島電鉄株式会社 | 江ノ電 |
| モビリティプラットフォーム株式会社 | MPF |
| 東急バス株式会社 | 東急バス |
| 株式会社サンオータス | サンオータス |
| 加和太建設株式会社 | 加和太建設 |
| 株式会社ドコモ・バイクシェア | ドコモ・バイクシェア |

### Excel出力形式

#### 全PT企業一括ダウンロード（ZIP）

ZIPファイルには以下が含まれます：
- **`全企業_集計結果_YYYYMMDD.xlsx`**: 全PT企業の集計を1ファイルに統合
  - 「全PT企業集計」シート: 全社分の集計表（`PT企業名`列付き）
  - 「自社交換分」シート: 全社分の自社交換レコード（存在する場合）
- **`{PT企業名}_集計結果_YYYYMMDD.xlsx`**: 各PT企業毎の個別ファイル
  - 「集計結果」シート
  - 「生データ」シート
  - 「自社交換分」シート（対象PT企業のみ）

#### bike_company別ローデータダウンロード

ダウンロードしたいbike_companyを複数選択してExcelを個別生成できます。
各ファイルには以下のシートが含まれます：
- **「ローデータ」シート**: 選択したbike_companyの交換記録（不要列を除外済み）
- **「自社交換分」シート**: 自社交換分が存在する会社のみ
- **「ピボット」シート**: bike_company × 自転車メーカー名のクロス集計（通常/自社交換の内訳付き）

> 注意: ローデータから `一致or請求`, `請求可否`, `BT残量区分`, `重複確認`, `対象BT残量` 列は除外されます。

全シートはExcelテーブル形式で出力され、フィルタや並び替えが容易に行えます。

## 🛠️ 技術スタック

- **Python 3.9+**
- **Streamlit**: Webアプリケーションフレームワーク
- **Pandas / NumPy**: データ処理・集計（ベクトル演算による高速処理）
- **OpenPyXL**: Excelファイルの読み書き・テーブル書式設定
- **concurrent.futures**: ThreadPoolExecutorによるExcel並列生成

## 📝 注意事項

- Excelファイルは `.xlsx` または `.xls` 形式に対応しています
- 全PT企業ZIPの生成はThreadPoolExecutorで並列処理されますが、大量データ（10万行以上）の場合は数分かかる場合があります
- 生データシートには選択したPT企業に絞られた交換記録のみが含まれます

## 🔧 トラブルシューティング

### パッケージのインストールエラー

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### ファイル読み込みエラー

- Excelファイルのフォーマットが正しいか確認してください
- 必須列（`user_company(所属)`, `user_name`, `自転車メーカー名`, `battery_remaining`）が存在するか確認してください
- ファイルが破損していないか確認してください

### 集計エラー

- データに欠損値が多い場合、集計結果に影響が出る可能性があります
- エラーメッセージを確認し、該当する行のデータを修正してください
